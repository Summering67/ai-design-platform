- 使用 Tailwind CSS 时，优先通过 `@theme` 将 CSS 变量映射为可复用的主题令牌。
- 优先使用函数式编程、箭头函数。
- CSS 变量、`@theme` 配置必须集中定义在外部 CSS 文件中，不在 React 组件内使用 `<style>` 或重复声明。
- CSS/SCSS 模块与对应的 TSX/JSX 组件文件放在同一个目录下。

## 样式职责划分

- 简单、一次性的尺寸、间距、排列和对齐优先使用 Tailwind。
- 优先使用 shadcn/ui 已有的 `variant` 和 `size`，禁止重复实现组件已有样式。
- 复杂布局、响应式规则、伪类、动画以及多处复用的样式使用 CSS Module。
- 禁止仅为一两个可直接表达的 Tailwind 属性创建 CSS Module Class。
- 不为每个 JSX 节点机械创建 Class；Class 必须表达组件区域、复杂状态或可复用样式。
- 组件内部结构固定时，可以通过根 Class 的直接子级选择器管理私有节点，选择器嵌套原则上不超过一层。
- CSS Module 已具有局部作用域，类名使用 `header`、`menu`、`account` 等简洁名称，不重复添加组件名称前缀。
- 只有重复使用或具有明确业务含义的尺寸、栏宽、间距才提取为 CSS 变量，禁止过早抽象一次性数值。
